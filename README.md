# CommitZip

افزونه‌ای سبک برای Chrome که لینک یک کامیت GitHub را می‌گیرد و **فقط نسخه نهایی فایل‌های تغییرکرده در همان کامیت** را، با حفظ ساختار پوشه‌های مخزن، در یک فایل ZIP دانلود می‌کند.

![CommitZip icon](extension/icons/icon128.png)

## امکانات

- پذیرش لینک کامل کامیت، `owner/repo@sha` یا SHA در صفحه همان مخزن
- تشخیص خودکار کامیت وقتی افزونه روی صفحه Commit در GitHub باز شود
- حفظ مسیر و ساختار اصلی پوشه‌ها داخل ZIP
- پشتیبانی از مخزن عمومی بدون توکن
- پشتیبانی از مخزن خصوصی با توکن اختیاری GitHub
- نمایش تعداد فایل‌های افزوده، ویرایش‌شده، تغییرنام‌یافته و حذف‌شده
- دریافت موازی فایل‌ها همراه با پیشرفت و امکان لغو
- رابط کاملاً فارسی و راست‌به‌چپ
- اجرای کامل در مرورگر؛ بدون سرور واسط و بدون وابستگی JavaScript خارجی

## نصب در Chrome

### روش سریع با فایل آماده

1. فایل `CommitZip-v1.0.0.zip` را دانلود و از حالت فشرده خارج کنید.
2. در Chrome به `chrome://extensions` بروید.
3. گزینه **Developer mode** را در بالای صفحه روشن کنید.
4. روی **Load unpacked** کلیک کنید.
5. پوشه استخراج‌شده را انتخاب کنید؛ همان پوشه‌ای که `manifest.json` داخل آن است.

> Chrome برای افزونه‌های خارج از Web Store، پوشه استخراج‌شده را می‌پذیرد و خود فایل ZIP را مستقیماً نصب نمی‌کند.

### نصب مستقیم از سورس

مراحل بالا را انجام دهید و در مرحله آخر، پوشه [`extension`](extension) همین پروژه را انتخاب کنید.

## استفاده

1. لینک کامیت را وارد کنید؛ برای مثال:

   ```text
   https://github.com/octocat/Hello-World/commit/7fd1a60b01f91b314f59955a4e4d4e80d8edf11d
   ```

   یا:

   ```text
   octocat/Hello-World@7fd1a60
   ```

2. روی **ساخت و دانلود ZIP** کلیک کنید.
3. محل ذخیره فایل را انتخاب کنید.

اگر در خود صفحه کامیت روی آیکون افزونه کلیک کنید، لینک به‌طور خودکار وارد می‌شود.

## مخزن خصوصی و توکن

برای مخزن خصوصی، بخش «توکن گیت‌هاب» را باز کنید و یک **fine-grained personal access token** با دسترسی فقط‌خواندنی به همان مخزن وارد کنید. دسترسی `Contents: Read-only` کافی است.

- توکن مستقیماً برای درخواست به API گیت‌هاب استفاده می‌شود.
- توکن به هیچ سرور دیگری فرستاده نمی‌شود.
- گزینه ذخیره‌سازی به‌صورت پیش‌فرض خاموش است.
- با فعال‌کردن گزینه ذخیره، توکن در `chrome.storage.local` پروفایل مرورگر نگه‌داری می‌شود؛ این محل رمزگذاری اختصاصی توسط افزونه ندارد.

## رفتار فایل‌های خاص

- **فایل حذف‌شده:** چون در نسخه نهایی کامیت وجود ندارد، داخل ZIP قرار نمی‌گیرد و تعداد فایل‌های کنارگذاشته‌شده در نتیجه نمایش داده می‌شود.
- **فایل تغییرنام‌یافته:** محتوای جدید با مسیر جدید وارد ZIP می‌شود.
- **فایل باینری:** بدون تبدیل و دقیقاً به‌صورت باینری دریافت می‌شود.
- **Git LFS:** چیزی که GitHub به‌عنوان محتوای Git ارائه می‌کند دریافت می‌شود؛ ممکن است این محتوا فایل اشاره‌گر LFS باشد.
- GitHub فهرست یک کامیت را حداکثر تا ۳٬۰۰۰ فایل برمی‌گرداند.
- سازنده داخلی از ZIP32 استفاده می‌کند؛ حداکثر اندازه خروجی ۴ گیگابایت است. به‌دلیل محدودیت حافظه مرورگر، آرشیوهای بسیار بزرگ توصیه نمی‌شوند.

## مجوزهای افزونه

| مجوز | دلیل |
| --- | --- |
| `activeTab` | تشخیص لینک کامیت از تب فعلی پس از کلیک کاربر روی افزونه |
| `downloads` | ذخیره فایل ZIP ساخته‌شده |
| `storage` | ذخیره اختیاری توکن با انتخاب کاربر |
| `api.github.com` | دریافت اطلاعات کامیت و محتوای مخزن خصوصی |
| `raw.githubusercontent.com` | دریافت فایل‌های مخزن عمومی بدون مصرف سهمیه API برای هر فایل |
| `github.com` | پشتیبانی از آدرس‌های محتوای خامی که GitHub برمی‌گرداند |

## توسعه و آزمون

هیچ پکیج runtime لازم نیست. برای اجرای آزمون‌ها، Node.js 20 یا جدیدتر کافی است:

```bash
npm test
```

برای ساخت بسته قابل انتشار:

```bash
npm run package
```

خروجی در `release/CommitZip-v1.0.0.zip` ساخته می‌شود.
